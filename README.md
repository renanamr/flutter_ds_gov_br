# Pacote Flutter - DS Gov.br

Este pacote fornece temas e componentes compatíveis com o **Design System do Governo Federal (DS Gov.br)** para aplicações Flutter.

## 📌 Versão do DS Gov.br
Atualmente baseado na versão **3.6.1** do DS Gov.br.

🔗 [Documentação Oficial do DS Gov.br](https://www.gov.br/ds/home)

## ✨ Recursos
- Tema personalizado seguindo as diretrizes do DS Gov.br.
- Componentes reutilizáveis alinhados ao design system.
- Suporte para cores, tipografia e estilos do DS Gov.br.

## 🚀 Instalação
Adicione a dependência no seu `pubspec.yaml`:

```yaml
dependencies:
  flutter_ds_gov_br:
    git:
      url: https://github.com/renanamr/flutter_ds_gov_br.git
